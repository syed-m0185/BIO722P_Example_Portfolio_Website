# Exploratory Data Analysis Project

## Context

The aim of this project was to explore a dataset, identify meaningful patterns, and communicate findings that could help answer a specific research question. The project provided an opportunity to apply data analysis techniques to a practical problem.

## My Contribution

I was responsible for preparing and exploring the data. My work included:

- Cleaning the dataset and checking for missing or inconsistent values.
- Using Python and pandas to organise and analyse the data.
- Creating visualisations with Matplotlib or Seaborn to identify trends and relationships.
- Summarising the results and documenting the analysis in a Jupyter Notebook.

## Outcome

The project strengthened my skills in data cleaning, exploratory data analysis, visualisation, and communicating technical findings. I produced a documented analysis with visualisations and a summary of the main findings.
